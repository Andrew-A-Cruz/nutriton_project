# App name contenders

**Chosen 2026-11-08: Logbite.** Support email: logbite.app@gmail.com. Internal IDs (bundle ID `com.andrewcruz.nutriton`, App Group, product IDs `com.nutriton.app.*`, the backup file's `"app": "nutriton"`) keep the old name on purpose.

Working notes for renaming Nutriton before launch. These are the results of name searches on the US App Store (Apple's search API) and the US Google Play store, last run 2026-11-08. "Clear" means no app had that name in its title or package ID. That isn't a trademark search, so do one before committing to a name.

## Shortlist

| Name | Why it works | Notes |
|---|---|---|
| **Logbite** | Short, punchy, says what it does | Top contender. Store title idea: "Logbite: Calorie & Macro Log" |
| **Logabite** | Reads as "log a bite", friendly | Longer. As one word it can read "Loga-bite"; the store title could be "Log a Bite" |
| **Chomplog** | Playful, easy to say | Eating word first |
| **Keepbite** | "Keep" fits local-only, private data | |

## Logbite vs Chomplog (research, 2026-11-08)

**Logbite**
- No app on either store uses it today. But a macro tracker by Arda Sen (App ID 6737899564) launched as "Macro Tracker: LogBite" in 2024. It's now "Calorie Counter - BiteSync", and it is also an on-device, privacy-first tracker. Old web pages still show the LogBite name.
- logbite.app was a beta activity logger, not food; the domain doesn't resolve now. logbite.com is registered (since 2019). logbite.co is free.
- @logbite: on Instagram, a food-review account; on X, an inactive account.
- No USPTO mark for LOGBITE was found. The nearest are LOGIBITE and LOGIBYTES.

**Chomplog**
- No app uses the exact name.
- "Chomp" itself is crowded among calorie trackers: Chomp: Simple Macro Tracker (RootCause LLC, iOS and Android), Chomp AI: Calorie Counter, Chompr, ChompChart and Chompy.
- CHOMPS is a big meat-stick brand in protein and fitness food. There are CHOMP trademarks in classes 5 and 30, and more are pending.
- chomplog.com is registered; chomplog.io and chomplog.co are free.
- The only Chomp meal log on the web is a self-hosted GitHub project.

**Verdict: Logbite.** Chomplog would be the fifth or sixth "Chomp" calorie app, and "chomp" suggests eating a lot, which works against the app's neutral, no-guilt tone. Logbite's only real risk is that the BiteSync app once used the name, and that app has moved on.

## Ruled out

**Rejected:**
- Macrodex, which is also the name of a dextran drug
- Honest Plate, which sounds like meal delivery
- Macrojot and Nutrijot ("not loving jot")

**Taken on a store:**
- Platewise, Bitelog, Snack Track, Nutrilog / NutriLogger, MacroNote, MacroCount

## Before choosing

- [ ] Search the USPTO trademarks (free at tmsearch.uspto.gov)
- [ ] Check that the Gmail address is free, e.g. logbite.app@gmail.com
- [ ] Check social handles, if wanted
- [ ] Rename: display name, in-app text, welcome pages, docs and docs/privacy.md. The bundle ID com.andrewcruz.nutriton stays.
